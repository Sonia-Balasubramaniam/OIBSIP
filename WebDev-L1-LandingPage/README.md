# 🏥 Task 1 — WellNest | Healthcare & Wellness Landing Page

A premium, fully responsive landing page for a fictional healthcare and
wellness brand, built with **HTML5 and CSS3 only** (no JavaScript), as part of
the **Oasis Infobyte Web Development & Designing Internship (Level 1)**.

## 📌 Project Overview

**WellNest** presents a modern healthcare brand with a sticky navigation bar,
an animated hero section, an about section with visual storytelling, a
six-card services grid, patient testimonials, a call-to-action band and a
detailed footer. Every visual effect — the mobile menu, floating hero cards,
ECG animation and scroll reveal — is achieved with pure CSS.

## 🎯 Objective

- Design a conversion-focused, professional landing page for a healthcare brand.
- Demonstrate advanced CSS skills: Flexbox, Grid, custom properties,
  animations and a JavaScript-free responsive mobile menu.
- Deliver a polished, accessible UI that works flawlessly across devices.

## ✨ Features

- **Sticky navigation** with 5 in-page links and a CSS-only hamburger menu.
- **Hero section** with headline, description, dual CTAs, live stats and an
  animated ECG card.
- **About section** with layered imagery, floating achievement badge and a
  feature checklist.
- **Services grid** — 6 cards (primary care, mental wellness, nutrition,
  physio, diagnostics, home care) with hover elevation.
- **Testimonials** — 3 patient review cards with avatars and star ratings.
- **CTA band** and rich **footer** with contact details, hours and link columns.
- **Pure-CSS interactivity**: hamburger toggle (checkbox hack), pulse
  animation, floating cards, wave divider, entrance animations.
- **Responsive** breakpoints at 1024px, 860px and 600px — no horizontal scroll.
- **Accessibility**: semantic landmarks, ARIA labels, visible focus rings,
  `prefers-reduced-motion` support.
